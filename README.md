# 🎯 Valorant Tactics & Strategy Board (Interactive Prototype)

A web-based tactical planning tool prototype designed for Valorant players and teams to visualize map strategies, coordinate agent abilities, and plan site executions.

## 📌 Project Overview & Status
- **Status:** In Active Development / Prototype Phase
- **Architecture:** Modular client-side JavaScript architecture (`boardCoords.js`, `dragdrop.js`, `abilities.js`, `zoom.js`, `state.js`).
- **Core Focus:** Canvas/board interaction, coordinate transformation, dynamic DOM manipulation, and state management.

## 🛠️ Built With
- **Frontend:** Vanilla JavaScript (ES6+ Modules), HTML5, CSS3
- **Design Pattern:** Modular UI & State Isolation

## 🚀 Features (Implemented & In Progress)
- [x] Board canvas layout and responsive container scaling
- [x] Modular script structure for tactical mechanics and coordinates
- [ ] Interactive agent icon positioning & drag-and-drop
- [ ] Ability trajectory mapping and line-up planning
- [ ] Exportable tactical snapshots
